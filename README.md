## Meta e MVP
Cadastrar empresa e proprietário, autenticar, cadastrar produto, registrar entrada e confirmar venda com baixa de estoque e conta a receber vinculada. Cancelamento, descontos, relatórios e IA ficam para refinamentos futuros.

## Contexto e uso de IA
O produto é o PI GoIAba; a loja piloto é ilustrativa. Registrar cliente real e validação das regras antes de apresentar o levantamento como validado. Roteiro estruturado com auxílio de ChatGPT a partir dos PDFs fornecidos pelo aluno. Cadastro do backlog não significa software implementado.
